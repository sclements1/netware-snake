# Security reporting

Please email **sclements@gmail.com** with the subject `NetWare Snake security`
for suspected vulnerabilities or exposed credentials. Do not post exploit
details, passwords or private keys in a public issue. Include the affected
version, impact and minimal reproduction steps with sensitive values redacted.

This is a volunteer project without a guaranteed response time. Security fixes
target the current development branch and the latest published release; older
releases do not have a separate maintenance commitment.

The saver does not send telemetry or capture application windows. Optional local
diagnostics can include display layout and process details. Review reports before
sharing them. Published Developer ID certificates, developer names and Team IDs
are public signing metadata; the matching private keys are confidential.
